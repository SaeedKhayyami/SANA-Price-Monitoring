# Contributing

This repository is primarily maintained as a portfolio project. Small bug fixes, documentation improvements, and reproducible issue reports are welcome.

Before submitting a change:

1. Do not include credentials, cookies, proprietary datasets, or personal data.
2. Keep runtime-generated files out of commits.
3. Verify the desktop application starts successfully.
4. Keep collector changes respectful of the target website's terms, robots policy, and request limits.
